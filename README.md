# JUDGE THE MEME

This is clone of the game "WHAT DO YOU MEME?"

## Play

**https://judge-the-meme.onrender.com**

Open the link, tap **Play online**, create a room and share the code, link or QR code with your friends.

> Hosted on Render's free plan: after about 15 minutes without visitors the server sleeps, so the first visit can take 30–60 seconds to load. Rooms reset when the server restarts.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
